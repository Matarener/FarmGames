# Ферма для Telegram Mini App

Изометрическая ферма на чистом JavaScript (ES-модули, Canvas 2D). Без фреймворков и сборки, со своим движком и своей скелетной анимацией.

## Запуск

Модули не работают через `file://`, поэтому нужен любой локальный веб-сервер:

- `tools\run-local.cmd` — двойной клик (нужен Node.js или Python), откроется http://localhost:8080
- или `npm run dev`

Полезные параметры адреса:
- `?debug` — FPS, уровень качества и масштаб рендера
- `?quality=low|mid|high` — принудительно выбрать качество (проверка поведения на слабом телефоне)

## Сборка

```
npm install
npm run build      # → dist/: один минифицированный бандл, CSS, index.html
npm run preview    # открыть собранную версию на http://localhost:8080
```

Папка `dist/` лежит в репозитории. При каждом пуше в `main` GitHub Actions пересобирает её и публикует на GitHub Pages (`.github/workflows/pages.yml`). Адрес: https://matarener.github.io/FarmGames/

## Подключение к Telegram

1. Адрес игры — GitHub Pages (выше) или любой другой HTTPS-хостинг с содержимым `dist/`.
2. В @BotFather: `/newapp` (или `/mybots → Bot Settings → Menu Button`) и укажите адрес `index.html`.
3. Внутри Telegram игра сама разворачивается на весь экран, отключает закрытие свайпом вниз, учитывает вырезы экрана, использует вибрацию и сохраняет прогресс в CloudStorage аккаунта (плюс localStorage).

  Perf.js                 определение мощности устройства и автоснижение качества
  Iso.js                  изометрия 2:1 (тайл 64×32)

  Sprite.js               offscreen-спрайты, затемнение, ГПСЧ

  World.js                генерация карты из seed, участки 10×10, сохранение разницы
  Farm.js                 логика фермы и отрисовка мира
  Player.js               фермер: путь, очередь до 6 действий, анимации

### Производительность на слабых устройствах
- Вся графика заранее рисуется в offscreen-канвасы, а в кадре выполняются только `drawImage`.
- Отрисовываются только видимые тайлы и объекты.
- Разрешение рендера ограничено по классу устройства (×1 / ×1.5 / ×2). Если кадр не укладывается в бюджет, разрешение снижается автоматически, затем FPS ограничивается до 30.
- В простое игра рисует 20 кадров в секунду, а в фоне останавливается полностью.
- Скелет фермера: 12 костей, на кадр одна матрица на часть тела.

### Фермер
Фермер рисуется покадрово: 4 направления по 8 кадров ходьбы в `assets/farmer/walk_*.png`. Их нарезает `python tools/cut_farmer.py` из листов `assets/source/walk_1..4.png` (вниз-влево, вниз-вправо, вверх-вправо, вверх-влево): убирает фон и тень, выравнивает кадры по ногам. Скелет в `farmer.js` остался для отсчёта времени действий и качания инструмента в руке.

### Как заменить графику на свою
Каждый спрайт — это `{canvas, w, h, ax, ay}`: картинка, её размер в мировых единицах и точка опоры. Точка опоры — центр клетки, на которой стоит объект. PNG грузится через `loadImage()` и подставляется вместо вызова `art.*` в `Farm.buildSprites()`.

Для персонажа замените спрайты частей в `farmer.js → parts()`: голова, туловище, плечо, предплечье с кистью, бедро, голень с ботинком, инструменты. Кости и анимации при этом остаются прежними.
