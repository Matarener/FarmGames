# Растения без подложки: задания для Codex (временная папка, удалить перед слиянием)

- `jobs.json` — 50 заданий для `tools/gen-art/gen_art.mjs`: 19 деревьев, 18 кустов, 9 пней (правка
  нынешней картинки: то же растение, но без травяного островка и земляного блока) и 4 варианта
  высокой травы (новый рисунок в нынешнем стиле).
- `refs/` — образцы: нынешние картинки на однотонном фоне того же цвета, что попросим у Codex
  (пурпурный, у розовых и белых растений — бирюзовый), чтобы он не рисовал чёрный фон.
- `out/` — результаты с компьютера Марка (`<имя>.png`, следующие попытки — `<имя>_2.png` …).

Запуск на компьютере Марка (рабочая копия ветки, gen-art берётся из ветки `claude/project-thread-su3mit`):

```
git checkout origin/claude/project-thread-su3mit -- tools/gen-art tools/gen-art.cmd
node tools/gen-art/gen_art.mjs art-candidates/nobase/jobs.json tree_oak bush_rose
```
