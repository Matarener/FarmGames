# Новые плодовые деревья: задания для Codex (временная папка, удалить перед слиянием)

Черёмуха (bird_cherry), слива (plum), груша (pear), абрикос (apricot), хурма (persimmon) — в стиле
без подложки (ветка `claude/project-thread-vrh61f`): без травяного островка, 3–5 травинок у корней,
без тени (тень рисует `slice_art.py`).

- `jobs.json` — первая очередь, 20 заданий: взрослое дерево с плодами, пень, иконка плода
  (`ui_<плод>`) и иконка саженца (`ui_sap_<вид>`) на каждый вид.
- `jobs2.json` — вторая очередь, 10 заданий: `tree_<вид>_bare` (без плодов; черёмуха — в цвету) и
  `tree_<вид>_young`. Образец для них — выбранное взрослое дерево из первой очереди:
  `refs/tree_<вид>_m.jpg` / `_c.jpg` (на пурпурном / бирюзовом фоне), их кладёт Claude после отбора.
- `refs/` — образцы стиля на фоне цвета ключа (иначе Codex иногда рисует чёрный фон):
  `style_tree_m` — яблоня без подложки, `style_young_m` — молодая яблоня, `style_stump_m` — пень дуба.
  Бирюзовый ключ — только у цветущей черёмухи (белые цветы); зелёные листья на бирюзовом фоне
  иногда вырезаются полупрозрачными.
- `out/` — результаты: `<имя задания>__<попытка>.png` и `notes.txt`.

Запуск на компьютере Марка (gen_art.mjs — исправленный, берёт картинки только из папки своей сессии
Codex: копия из `D:\FarmGames-nobase\tools\gen-art`):

```
node tools/gen-art/gen_art.mjs art-candidates/fruit/jobs.json tree_plum stump_plum
```
